# Visual Basic (.NET) — plano de treinamento (o que precisa constar)

**Objetivo**: cobrir tudo pra o expert responder qualquer pergunta sobre VB.NET (e VBA).
**Expert sugerido**: família em `dotnet_experts` ou `legacy_experts`. **Total est.**: ~50 lições.
**Convenção**: `treinamento_vb/<família>/<subsetor>/*.md` → path = [família, subsetor].

## core/ — ~24
o que é VB.NET; sintaxe básica; variáveis e `Dim`; tipos de dados; `Option Strict`/`Explicit`; operadores; strings; controle de fluxo (If/Select Case); loops (For/While/Do); functions e subs; parâmetros (ByVal/ByRef); arrays; collections; escopo; conversões; tratamento de erros (Try/Catch); comentários; nullable; My namespace.

## oop-net/ — ~16
classes e objetos; propriedades; construtores; herança; polimorfismo; interfaces; módulos; eventos e delegates; namespaces; generics; LINQ; acesso a dados (ADO.NET); coleções genéricas; encapsulamento; shared members.

## aplicacoes-ecossistema/ — ~10
Windows Forms; WPF (visão geral); controles e eventos; data binding; VBA (Excel/Office); macros; interop com Office; migração para C#; .NET Framework vs Core; boas práticas; comparação com C#.
