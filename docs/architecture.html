1 The idea

The name is Py (Python) + axon (the fiber that connects neurons). The goal isn't to compete with PyTorch — it's to learn by building: to understand how a Tensor lives in memory, how autograd computes gradients, and how to squeeze performance out of the hardware. Python provides the ergonomics; C++ does the heavy lifting.

2 Layered architecture

3 The Tensor

The fundamental building block: an N-dimensional array in a contiguous buffer (row-major). It uses shape + strides to enable views (transpose, slice, reshape) without copying data — the same technique as NumPy. Transposing a matrix becomes just swapping two numbers.

class Tensor {
    std::shared_ptr<Storage> storage;   // raw buffer (owns the data)
    std::vector<int64_t> shape;          // dimensions
    std::vector<int64_t> strides;        // steps -> enables views without copying
    bool requires_grad = false;          // participates in autograd?
    std::shared_ptr<Tensor> grad;        // accumulated gradient
    std::shared_ptr<Function> grad_fn;   // node that created me in the graph
};

4 Autograd (automatic differentiation)

Each operation records how to compute its gradient. On the forward pass, in addition to the result, it creates a node that stores the inputs. On the backward pass, it walks the graph in reverse, applying the chain rule.

ab→MatMul →ReLU→loss — .backward() flows back accumulating gradients →

Example — matrix multiplication C = A·B:  grad_A = grad_C · Bᵀ  and  grad_B = Aᵀ · grad_C.

5 Where the performance lives

Each kernel has a naive version (correct, reference) and fast versions measured in benchmarks.

Case study: matmul

StepTechniqueExpected gain
1Naive (3 loops)baseline
2Reorder loops (cache-friendly)sequential access
3Blocking / tiling (fits in L1/L2)fewer cache misses
4SIMD (AVX2 = 8 floats, AVX-512 = 16)vectorization
5OpenMP (multithreading)× cores
6CUDA / cuBLAS (GPU)massively parallel
Golden rule: nothing lands without a test, and every hot path comes with a number — "how many times faster did it get?".

8 What the API will look like

import pyaxon as ax
import pyaxon.nn as nn

x = ax.tensor([[0,0],[0,1],[1,0],[1,1]])
y = ax.tensor([[0],[1],[1],[0]])

model = nn.Sequential(
    nn.Linear(2, 8), nn.ReLU(), nn.Linear(8, 1),
)
opt = ax.optim.Adam(model.parameters(), lr=0.05)

for epoch in range(1000):
    pred = model(x)
    loss = ax.mse_loss(pred, y)
    opt.zero_grad()
    loss.backward()      # autograd running in C++
    opt.step()
